The Mirage Effect in Large Language Models

The mirage effect is the false appearance of sudden, emergent ability in large language models (LLMs). The key point is not that the model suddenly learned a new skill at one scale; it is that a discontinuous metric can turn smooth improvement into a sharp-looking jump.

The actual phenomenon

A capability can improve smoothly while the reported benchmark score looks like it appears from nowhere.

Suppose an LLM gradually gets better at assigning higher probability to the correct answer as model scale increases. If the benchmark reports only exact match, multiple choice accuracy, or another thresholded score, then many small improvements remain invisible until they cross the threshold.

That threshold crossing creates the visual illusion of emergence: below the threshold the model looks incompetent, above it the model looks competent, even if the underlying skill changed continuously.

Smooth latent improvement Discontinuous metric Apparent sudden jump

What it is not

This is not mainly about hallucination or prompt brittleness.

Hallucination means producing false content. Prompt brittleness means performance changes under rewording. The mirage effect discussed here is about measurement: the curve you see depends on the metric you choose.

How a metric creates the mirage

The discontinuity is introduced by the evaluation rule, not necessarily by the model's internal learning curve.

The math in one picture

A hard threshold can convert a smooth variable into a step function.

Let \(s(N)\) be a smooth latent skill score for a model with size \(N\), and let \(\tau\) be the threshold required for a benchmark item to count as correct.

\[ \boxed{A(N) = \mathbf{1}\{s(N) > \tau\}} \]

Here \(A(N)\) is the reported accuracy for one item. Even if \(s(N)\) rises gradually, \(A(N)\) jumps from 0 to 1 the instant \(s(N)\) crosses \(\tau\).

Why this matters

The same experiment can support two different narratives depending on whether the metric preserves smooth progress.

If you plot only a thresholded score, you may conclude that a new ability emerged at a critical scale. If you inspect a continuous measure such as probability assigned to the correct answer, loss, calibration, or partial credit, the same result may look like ordinary scaling.

The conservative interpretation is: before claiming emergence, check whether the effect survives a metric change.

How to test whether emergence is real

A genuine discontinuity should not disappear when the measurement rule changes.

  • Plot continuous scores, not only exact-match accuracy.
  • Check whether the jump location changes under different thresholds.
  • Use partial-credit metrics when the task has degrees of correctness.
  • Report the raw scaling curve alongside any binary success rate.

Bottom line

The mirage effect says that some “emergent abilities” may be artifacts of how we score models.

The model may still be improving, and scale may still matter. The correction is narrower and sharper: do not infer a sudden new capability from a sudden jump in a discontinuous metric until you have checked the underlying continuous behavior.

TL;DR: The mirage effect in LLMs is the illusion that a capability appears abruptly with scale when the underlying ability may have improved smoothly. Thresholded metrics such as exact match can hide gradual progress and then reveal it as a fake phase transition.
